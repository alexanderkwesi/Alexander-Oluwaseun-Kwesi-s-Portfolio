# Alexander Oluwaseun Kwesi Portfolio

Static GitHub Pages-ready portfolio built around curated case studies from the `alexanderkwesi` GitHub repositories.

## Files

- `index.html` - one-page portfolio with featured case studies, project lab, skills and contact sections
- `styles.css` - custom workbench/case-study visual design and responsive layout
- `script.js` - mobile navigation and back-to-top behaviour

## Featured Case Studies

- Crypto Web API Scraper UI and Data Visualisation
- CSIRO Biomass App
- DocRevisor
- veriCourses
- Portfolio API
- Checkmate MVP
- CleanPro
- Dino Dashboard

## Previous Featured Builds Included

- Uppound
- Maison
- Predictive Analytics Platform
- HR Management System

## Deploy

Copy these files into the root of the GitHub Pages repository that currently hosts:

`https://alexanderkwesi.github.io/Alexander-Oluwaseun-Kwesi-s-Portfolio/`

Then commit and push to GitHub. No build step is required.

## Before Publishing

- Confirm each repository link is public.
- Add live demo links beside the repository links where deployments exist.
- Replace any inferred project wording with exact stack details once each repo README is final.
